# Legacy Project Gracemeria classification

The public legacy repository was mostly empty `.gitkeep` subsystem scaffolding.

- **KEEP/MIGRATE**: project name/identity, MIT licence, legal no-game-data policy, useful `.gitignore` intent.
- **REWRITE**: README, CMake/build setup, version/revision metadata.
- **OBSOLETE/DELETE**: `src/core/main.cpp` old `xenon::Runtime` bootstrap; empty `audio`, `renderer`, `online`, `input`, `saves`, `content`, `game` subsystem trees; empty architecture/development docs; empty regional TOMLs; placeholder tools.
- **RESEARCH-ONLY**: historical renderer/networking intent where it helps explain why the old architecture was replaced.

The new repository does not preserve empty folders for backwards compatibility.
